# Glossário — Frameworks Front-end e Hackathon

| Termo | Significado no contexto do curso |
|---|---|
| **API** | Interface que permite a comunicação entre aplicações ou serviços, geralmente por endpoints HTTP. |
| **Backlog** | Lista priorizada de funcionalidades, correções e melhorias ainda por fazer. |
| **Deploy** | Publicação de uma aplicação em ambiente acessível aos usuários, por exemplo na Vercel ou Render. |
| **Framework** | Estrutura de desenvolvimento que oferece convenções, ferramentas e fluxo para construir aplicações. |
| **Hackathon** | Atividade intensiva de ideação e desenvolvimento colaborativo de uma solução para um tema/desafio. |
| **localStorage** | Armazenamento chave/valor do navegador, persistente naquele perfil/dispositivo e sem sincronização automática entre usuários. |
| **ODS** | Objetivos de Desenvolvimento Sustentável da ONU; a referência do Hackathon conecta o tema às ODS 2 e 12. |
| **React** | Biblioteca JavaScript para criação de interfaces por componentes. |
| **React Router** | Biblioteca de roteamento usada para navegar entre telas sem recarregar a SPA. |
| **SPA (Single-Page Application)** | Aplicação web que atualiza a interface no cliente; rotas diretas precisam de fallback para o documento principal no host. |
| **Tailwind CSS** | Framework CSS baseado em classes utilitárias. |
| **Vercel** | Plataforma de publicação de aplicações web; neste projeto, o endereço público só deve ser registrado depois do deploy. |
| **Vite** | Ferramenta de desenvolvimento e build para aplicações web modernas. |
