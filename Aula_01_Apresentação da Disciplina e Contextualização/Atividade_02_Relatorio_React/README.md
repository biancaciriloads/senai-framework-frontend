# Atividade 02 — Relatório técnico sobre React

Este diretório contém o relatório técnico sobre React solicitado na Aula 01, em PDF e HTML editável.

## Arquivos

- [Relatório em PDF](./Relatorio_Tecnico_React.pdf): versão para leitura e entrega.
- [Fonte HTML](./Relatorio_Tecnico_React.html): conteúdo editável usado para gerar o PDF.

## Antes da entrega

Preencha o nome do estudante ou dos integrantes no campo indicado na capa do relatório. O exemplo prático analisa o gerenciador de notas React já existente em `Aula_05_Consumindo APIs no Front-end/Atividade_aula05/projeto_notas_front/projeto_notas_front`.

O documento discute as características, vantagens, limitações, aplicações e decisões técnicas do React, com referências à documentação oficial e ao projeto existente. O conteúdo é uma análise técnica; não afirma a realização de testes de build nem a publicação de um novo projeto.
