# Jogo de Adivinhação

Aplicação da Atividade 01 da Aula 01, desenvolvida com HTML, CSS e JavaScript puro (Vanilla JS).

## Funcionalidades

- Gera um número secreto aleatório entre 1 e 100.
- Informa se o palpite deve ser maior ou menor.
- Conta as tentativas e permite reiniciar o jogo após acertar.
- Aceita palpites pelo botão ou pela tecla Enter.

## Executar localmente

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências.

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: estilos e layout.
- `script.js`: regras e interações do jogo.
