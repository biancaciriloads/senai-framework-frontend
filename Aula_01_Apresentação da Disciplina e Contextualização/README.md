# Aula 01 — Apresentação da Disciplina e Contextualização

## Objetivo
Apresentar a disciplina **Frameworks Front-end**, contextualizar o desenvolvimento front-end moderno, introduzir conceitos fundamentais (Vanilla JS, arquitetura web, UX/UI) e definir a metodologia e critérios de avaliação do semestre.

---

## Principais Conceitos e Tecnologias

| Conceito | Descrição |
|---|---|
| **Desenvolvimento Front-end** | Camada visual de interação com o usuário; interfaces, organização de elementos, UX, integração com back-end |
| **Vanilla JS** | JavaScript puro, sem bibliotecas ou frameworks externos; base essencial do front-end |
| **Arquitetura Web e UX/UI** | Escopo, prototipação, usabilidade, validação de ideias |
| **Frameworks Front-end** | React, Vue, Angular, Next.js — padronizam e aceleram criação de interfaces complexas |
| **Git e GitHub** | Versionamento distribuído, controle de versão, colaboração |
| **Deploy (Vercel)** | Publicação de aplicações estáticas/modernas com CI/CD via Git |
| **Metodologia** | Aulas expositivas/dialogadas, discussões, estudos de caso, integração teoria-prática-mercado |
| **Avaliação** | 55% Avaliação Docente (Projeto 20%, Apresentação 20%, Atividades 15%), 35% Projeto Integrador, 10% Autoavaliação |

## Atividades da Aula

### Atividade 01 (Individual/Guiada)
- Criar projeto simples em Vanilla JS (HTML, CSS, JavaScript)
- Conectar IDE ao GitHub e realizar deploy no Vercel
- **Entrega:** Aplicação publicada + repositório versionado

### Atividade 02 (Grupo — 3 a 5 alunos)
1. Formar equipes fixas para o semestre
2. Criar repositório principal do grupo no GitHub com `README.md` resumindo a Aula 01
3. Elaborar relatório técnico (PDF, mínimo 5 páginas) sobre um Framework Front-end:
   - Características principais
   - Vantagens
   - Aplicações no mercado
   - Exemplo prático em projeto Web
